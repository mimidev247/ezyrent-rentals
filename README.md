# EzyRent Property Listing
A clean, modern React interface for browsing Nigerian rental properties. The app focuses on fast discovery, simple filtering, and clear property details in a mobile‑first layout.

# Highlights
- Responsive property grid (3 columns desktop, 2 tablet, 1 mobile)
- Search by property name, filter by location, sort by price
- Price range filter and pagination for easy browsing
- Property details modal with full description and features
- Booking form for inspections with validation
- Save listing action with toast feedback
- Loading skeletons and empty state messaging

## Screens
# Property Listings
- Header: “Available Rentals” with a supportive subtitle
- Controls bar: search, location filter, price range, price sort
- Cards show image, location badge, price in Naira, and features

### Property Details Modal
- Large property image with location badge
- Price display and feature highlights (beds, baths, parking)
- Full description
- Primary and secondary CTA buttons

### UI States
- Loading skeletons during simulated load
- Friendly empty state when no results match filters

## Sample Data
Includes 10+ realistic listings from Lagos, Abuja, and Port Harcourt with varied prices, sizes, and amenities.

## Tech
- React + Vite
- Tailwind CSS
